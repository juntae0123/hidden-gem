# 메인/네비 디자인 개선 — 적용 내역 + 백로그

원칙: 취향 분석이 이 서비스의 차별점이므로, 진입 3초 안에
"내 취향을 분석해 숨은 게임을 찾아준다"가 전달되어야 한다.

## 오늘 적용됨 (2026-08-28)

**메인 히어로 (src/app/page.tsx)**
- 헤드라인: "당신이 좋아할 게임, 데이터는 알고 있어요"
- 신뢰 카피: "스팀 게임 4,190개 × 60개 지표로 분석한 나만의 게임 취향"
  — 구체적 숫자가 신뢰를 만든다
- Primary CTA 하나만 크게: [내 취향 분석하기] → /search
- 검색창은 CTA 아래 유지 + "문장으로 검색해보세요" 힌트

**네비게이션 (components/layout/Navbar.tsx)**
- 높이 h-14(56px) → h-16(64px), 탭 13px → 14px + 패딩 확대(px-4 py-2)
- 로고 확대(text-base font-semibold), 아이콘 버튼 32 → 36px (터치 타깃)
- 취향 분석 탭은 기존 강조 유지

**측정 (umami 커스텀 이벤트)**
- `hero_taste_cta` — 히어로 CTA 클릭
- `nav_taste_click` — 네비 취향 분석 탭 클릭
- 배포 후 1주 단위로 클릭률 비교해 카피/위치 조정. 감이 아니라 숫자로.

## 백로그 (효과 순)

1. **샘플 취향 DNA 카드**: 히어로 옆에 실제 결과물 미리보기 렌더
   (예: 레이더 차트 "본능적 짜릿함 68% · 지적 쾌감 22%...").
   "이런 결과를 받는다"가 보여야 클릭 동기가 생긴다. RadarChart 컴포넌트 재사용.
2. **검색 0건 폴백**: 빈 화면 대신 "비슷한 vibe의 게임" 추천 노출.
3. **게임 카드 점수 문장화**: "87점"보다 "당신 취향과 87% 일치".
   score_breakdown은 hover/탭 상세로.
4. **모바일 하단 탭바**: 햄버거보다 도달률 좋음 (발견/분석/검색/마이).
5. **첫 방문 1회성 툴팁**: 최대 3개 ("여기서 취향 분석" 등). 그 이상은 소음.
6. **로딩 문구**: Skeleton에 "60개 지표 비교 중..." 진행 문구로 체감 시간 감소.
