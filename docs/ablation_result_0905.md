## 1. 확정된 것 — 어제 내가 틀린 것부터

### X-Factor 는 선택 게이트였고, 유명작을 올리는 통로였다. (확정)
- 전체 풀에서 **X-F < 15.6 이 88.7%**, 18점 포화는 **7.7%** 뿐이다. 상위 10 이 전원 15.6~18 이었던 것은
  전체의 11% 안에서만 뽑혔다는 뜻 — **게이트다.**
- `v6 − X-Factor`: 상위 20 유지 **2~5/20**, spearman 0.86~0.93. 빼면 상위권이 거의 전부 바뀐다.
- `v6 X-Factor 만`: 상위 20 의 **교사 비율 0.90, 리뷰 중앙값 19,700** (5개 프리셋 전부 동일 — 질의와 무관하니 당연).
  Core 만으로는 교사 비율 0.15~0.60, 리뷰 중앙 84~625. **X-Factor 가 유명작을 끌어올리는 항이었다.**
  어제 "보류"했던 "X-Factor ↔ 인기도" 연결이 이걸로 확인됐다.

**어제 내 판정이 틀렸다.** 홀드아웃 150건에서 100% 포화를 보고 "인기작 풀에서는 상수, 가설을 '미결'로 강등"
이라고 썼다. 홀드아웃은 **교사 인기작만** 담은 편향 표본이었다 — 전체 풀의 7.7% 에 속하는 게임만 보고
전체를 말했다. R3(재검증)의 "강한 가설"이 맞았고, 내 강등은 `system_invariants.md` §4 의 **C 분류(분포에
대고 검증 안 함)** 를 그대로 반복한 것이다. 표본이 어디서 왔는지를 먼저 물어야 했다.

### 상위 10 의 σ 는 전체 풀을 심하게 과소평가했다. (확정)
Core6 σ: 상위 10 에서 1.14 → 전체 풀 11.6~16.0. 선택 절단 판정(어제 §11-2)이 맞았다.

### Gem 은 지금 거의 영향이 없다.
`v6 − Gem`: spearman 0.995~0.997, 상위 20 유지 14~17/20. 6점 예산 + 노이즈 입력이면 이 정도다.
증거 지수로 바꾸고 예산을 올려야 "발굴" 정체성이 점수에 실린다 (R-1', R-3).

- rbo·상위 20 유지 0~4/20: 상위권은 전부 다시 짜였다. 예측대로.

2. **모집단 차이 (보정 대상 아님)**: 액션 프리셋의 세 지표는 편향이 거의 없다(reflex +0.05, pacing +0.27,

   pacing 9 인 게임들**이기 때문이다. 취향 일치로는 맞는 답이다. 유명작을 내리는 건 Core 의 일이 아니라
   **gem(발굴) 과 히든젬 필터(`max_review_count`)의 일**이다 — PRD 의 역할 분담이 그렇다.
   Core 를 비틀어 인기작을 깎으면 "취향에 맞는 게임"이라는 1번 전제를 깬다. 하지 않는다.

원자료 `data/audit/ablation/ablation_after_calibration_20260905.txt`.

| 프리셋 | 예측 | v7 교사비율 1회차 → 2회차 | 판정 |
|---|---|---|---|
| 힐링 | 하락 | 0.70 → **0.60** | 맞음 (그러나 v7 Core 만은 0.60 → 0.85 로 **상승**) |
| 서사 | 하락 | 0.50 → 0.50 | **틀림** (narrative_depth 보정했는데 변화 없음) |

### 왜 틀렸나 — 보정의 형태가 잘못됐다
공포 프리셋은 `cozy_factor: 0` 을 목표로 한다. 보정식 `cozy = +0.77 + 0.97x` 는 학생의 **0 을 0.77 로** 민다.
교사는 공포 게임에 cozy 0 을 주고, 학생도 0 을 줬는데, 보정 후 학생만 0.77 이 되어 목표 0 에서 멀어졌다.
→ 학생 게임이 공포 상위 20 에서 전부 밀려났다(1.00). **평균 편향 +0.71 은 중간 구간에서 나온 것인데
절편은 0 에도 같은 이동을 강제한다.** 형태가 틀렸다.

원점 고정(y = b·x)으로 바꿔 보면(도구에 옵션 추가, `ZERO_MASS_FOR_ORIGIN`): cozy 1.12x, humor 1.15x, puzzle 1.20x 인데
**보정 전후 MAE 가 같다(0.83 → 0.83)**. 즉 편향은 비례 스케일도 아니다. 실제 모습은 **바닥 효과** — 교사가 1~2 를 주는
곳에 학생이 0 을 준다(모집단 cozy 0 비율 교사 20.6% / 학생 35.7%). 선형 어떤 형태로도 고칠 수 없다.
narrative_depth 는 홀드아웃에서 0 비율 7% 라 절편식이 통과했지만 **모집단에서는 25% 가 0** — 같은 문제를 25% 의 게임에 만든다.

### 판정
- **R-10 철회. `--revert` 로 원본 복원.** 이득(힐링 −0.10)보다 해(공포 +0.15, 0-목표 전반의 왜곡)가 크고,
  편향의 실체(바닥 효과)가 선형 보정의 가정과 다르다.
- 교사 비율이 높은 것은 Core 가 아니라 **발굴 층(gem 증거 + 히든젬 필터)** 이 처리한다. 원래 역할 분담으로 돌아간다.
  힐링에서 v7(gem 포함) 0.60 vs v7 Core 만 0.85 — 지금 6점 gem 만으로도 상위 20 을 0.25 움직인다. 증거 지수 + 예산 12 면 더 움직인다.
- 도구의 원점 고정 옵션은 남긴다(나중에 바닥 효과를 다른 방식으로 다룰 때 기준선). 지금은 적용 안 함.
- **X-Factor 결론은 2회차에서도 동일**: X-F<15.6 89.4%, 18점 7.1%, X-Factor 만 정렬 교사 0.90 / 리뷰 19,700.

### τ 판정 — 그리고 내가 도구에 적어둔 규칙이 방향이 반대였다
v7 상위 20 점수 폭 1.7~2.8. 가우시안은 거리 0 근처가 평평해서(1 − x²) 근접 후보 20개가 2점 안에 몰린다.
어제 적은 "5 미만이면 τ 를 올린다"는 **반대다** — τ 를 올리면 더 평평해져 폭이 더 좁아진다. 폭을 넓히려면 τ 를 내리거나
0 근처 기울기가 있는 커널(exp(−d/τ))로 바꿔야 한다. 그러나 τ 를 내리면 3점 어긋남의 페널티가 더 커진다(셀프 피드백 3-c).
두 요구가 충돌하므로 **τ 는 3.5 유지, 커널 형태는 결정 보류**. 상위 20 이 96~98 에 몰리는 것은 "전부 취향에 맞는 후보"라는
뜻이기도 하다. 도구의 안내 문구는 방향을 고쳤다.

### 왜 틀렸나 — legacy gem 이 하던 '유명작 억제'를 evidence gem(예산 6)은 못 한다
- s4(legacy) 에서 정착 게임의 gem 은 3.2~5.0 이었다 (Monument Valley 8,830 리뷰에 5.0, TIS-100 4.6 …). LLM 백분위 + review_bonus × confidence 가
  중간 인기작에도 4~5 점을 줬다. 유명작(≥20k)은 gem_factor 0 으로 0.
- s5(evidence) 에서 같은 게임들은 2.2~2.6 (μ36/100 × 6). 공통 게임 gem 변화 평균 −1.0 ~ −1.8, 최소 −3.1.
- 유명작은 양쪽 모두 0 → 정착 게임이 1~3 점 잃은 만큼 **상대적으로 유명작이 올라왔다**. v6 의 Core+X-Factor 는 유명작(잘 만든 게임, X-F 포화 18)이 높으므로
  gem 4~5 가 있어야 정착작이 이기던 구조였다. 즉 legacy gem 의 "크기"가 유명작 억제를 하고 있었고, evidence 는 모양은 맞지만 예산 6 에서는 크기가 부족하다.
- 이건 s5 상태(v6 + evidence)를 **배포하면 안 된다**는 뜻이다. Hidden Gem 의 취향 추천 1페이지에 Sims 4·Celeste·BG3 가 있으면 제품 명제와 어긋난다.

### v7 에서는 같은 문제가 없다 (절제 표)
- evidence 모드 절제에서 'v7 (Core + Gem)'(예산 87+12)의 리뷰 중앙값: 힐링 1,285 / 전략 1,012 / 서사 2,784 / 액션 691 / 공포 995 — v6 기준(4,105~10,909)의 1/3~1/10.
  유명작은 상위 20 에서 사실상 빠진다. 예산 12 × μ0.36 = 4.3, max 8.5 가 Core 상위 폭(1.9~2.5)을 넘기 때문.
- 교사 비율 1.00 은 **품질 지표가 아니다**(R-13): default 풀의 학생 929건은 전부 '신작'이라 gem_factor 0 이고, 상위가 gem 으로 갈리면 정착(=교사) 게임만 남는다.
  이는 R-11 의 설계 결과다 — 신작은 신작 리그에서 보여준다.
- v7 상위 5 는 다섯 장르 전부 장르 방향이 맞다 (힐링 Petal by Petal·Spilled!·Tiny Isle, 전략 Siralim Ultimate·Hex of Steel, 서사 Citizen Sleeper·SKALD,

## 8. s8 — 백필 완료 후 모수 증가 효과 (2026-09-06 밤, 실행 전 예측)

`too_new`(발굴 지수 대상 아님)로 잡혔다. gem `ok` 는 3,219 로 **그대로**(전부 교사 코호트).
즉 **발굴 층의 모수는 안 변했고, 신작 층의 모수만 1.5배 이상 커졌다.**

측정 방식 주의: s7 은 로컬 API, s8 은 운영 API 에서 수집한다(백필이 `--target prod` 였으므로
로컬 DB 는 이제 뒤처져 있다). s7 시점에 운영과 로컬이 동일함을 확인했고 코드·플래그(v7/evidence)도
같으므로 비교는 성립한다. 단 "같은 DB 를 두 번 찍은 diff" 가 아니라 **모수가 커진 효과**를 본다.

### 예측 (돌리기 전에 적는다)
1. **취향 5개 시나리오**: 상위 10 거의 유지(각 8~10/10). 발굴 대상 모수가 안 변했기 때문.
   `gem_percentile 118건 갱신` 때문에 한두 칸 이동은 있을 수 있다.
2. **랭킹 new(신작 리그)**: **크게 바뀐다.** 신규 4,465개 대부분이 신작 구간이라 누적 리뷰 상위가 새로 유입된다.
   카나리아(메챠 카멜레온)가 1위를 **유지 못 할 가능성 50%** — 이 경우는 실패가 아니라 정상이다.
   판단 기준: 새 1위가 "누적 리뷰 더 많고 Wilson ≥0.70" 이면 R-17 정렬이 제대로 작동한 것.
   반대로 리뷰 수가 더 적은데 위로 올라왔다면 정렬 버그다.
3. **랭킹 steady**: 변화 없음(정착작 모수 불변).
4. **랭킹 rising**: 변화 작음. 신규 게임엔 리뷰 이력이 1점뿐이라 속도 계산이 안 된다.
5. **시맨틱 3개**: 소폭 변화. 후보 풀이 커져 임베딩 상위에 신작이 끼어들 수 있다.
   10/10 유지면 qa 캐시·검색 안정성 확인, 3개 이상 바뀌면 신작 유입 영향으로 해석.

소수점까지 동일한 것이 오히려 정합성 근거다 — 모수가 안 바뀌었으니 점수가 바뀌면 그게 버그다.

**③ 시맨틱에 새로 들어온 6개는 전부 백필 신작**(In Trusted Hands 139 / holoVillage 532 / Soul Touch 1,156 /

발굴 취지와 같은 방향이다. 어제 세운 "시맨틱 3개가 10/10 이어야 qa 캐시 검증" 기준은 **이번 비교에는 적용 불가**
(모수가 변했다). qa 캐시 검증은 모수 고정 상태에서 따로 해야 한다.

**④ rising 이 비어 있다 — 이번 s8 의 진짜 발견.**

`prod_sync` 로 한 번에 넘어갔고 백필분도 최초 1회 조회뿐이라, **같은 게임의 두 시점 스냅샷이 없으면 Δ 가 계산되지 않는다.**
