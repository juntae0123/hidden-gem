네가 제안한 52개 지표 확장과 JSONB 5분할 스키마, Progressive Disclosure UI 전략 모두 완벽해. 우리가 원하던 압도적인 퀄리티야. 당장 이 스키마로 확정하고 진행할게.

[New Crucial Requirement: Multilingual Input & Localized Korean Output]
이제 우리가 실제 GPT-5.4 Batch API에 넣을 **[최종 데이터 추출용 시스템 프롬프트]**를 네가 직접 작성해 줬으면 해. 단, 프롬프트를 짤 때 아래의 '다국어 처리' 조건을 반드시 강력하게 지시해야 해.

1. 원본 데이터의 언어 장벽 파괴: 스팀 설명, 유저 태그, 메타데이터 등 입력(Input)되는 데이터는 90% 이상이 영어(또는 기타 외국어)야. 모델이 이를 완벽히 해독해야 해.
2. 100% 한국어 로컬라이징 출력: JSON의 결과물 중 텍스트 필드(`content`, `reasoning` 등)는 반드시 한국어로 출력되어야 해. 
3. 번역투 절대 금지 (Gamer Slang): 단순 기계 번역이 아니라, 한국의 진짜 하드코어 게이머들이 쓰는 찰진 어휘(예: "뇌지컬", "피지컬", "노가다", "찍먹", "파밍" 등)를 활용해서 유저가 읽었을 때 "이 추천 엔진 진짜 겜잘알이네"라고 느끼게 만들어야 해.

[Your Mission]
위의 다국어 조건과 네가 제안한 52개 지표, JSONB 스키마를 모두 적용해서, **우리가 Batch API의 `system_prompt`로 그대로 복사해서 쓸 수 있는 [최종 시스템 프롬프트(Master Prompt)]를 영어와 한국어를 적절히 섞어서 가장 효과적인 형태로 작성해 줘.** 모델이 JSON 외에 다른 헛소리(마크다운 등)를 뱉지 않도록 엄격한 출력 통제 조건도 꼭 넣어줘!
